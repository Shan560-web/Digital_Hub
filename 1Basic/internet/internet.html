What is a Internet

What is a web browser

A browser is a software application that allows you to access and view websites on the internet. It retrieves web pages, displays text, images, and videos, and lets you interact with online content.

Web Address

A web address, or a Uniform Resource Locator (URL), is a unique reference that directs you to a specific page, file or photo on the internet. Without a web address, users cannot access a webpage.
(Eg. https://www.wikipedia.com/)

Safe Browsing Tips

Safe websites begin with https:// (“s”) mean secure. .
eg. https://www.microsoft.com/

*Avoid entering websites that start with only http:// or  look suspicious.
*Avoid clicking pop-up adds and suspicious links.
*Always use secure network connection.
*Use updated browsers and updated antivirus.
